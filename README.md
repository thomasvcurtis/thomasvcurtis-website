# Thomas Curtis - Personal Website

My personal portfolio website and blog built with modern web technologies.

## 🛠️ Tech Stack

- **Framework**: [Astro](https://astro.build/) for static site generation
- **Language**: [TypeScript](https://www.typescriptlang.org/) for type safety
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with [shadcn/ui](https://ui.shadcn.com/) components
- **Content**: MDX for blog posts with React components
- **Hosting**: Vercel
